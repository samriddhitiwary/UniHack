# Contributing

CatalogIQ AI uses spec-driven development. Before implementation, add or approve one narrowly scoped specification in `docs/specs`, document its acceptance criteria and explicit exclusions, and implement only that specification.

Use JavaScript (`.js` and `.jsx`) in the frontend and Python 3.12 in the backend. Changes must pass all commands in the root README. Do not commit secrets, generated build output, local databases, or files under local storage directories.
